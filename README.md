# PlumURL
PlumURL is a modern URL shortener designed for fast link creation, clean analytics, and reliable redirect handling. It is intended as a full-stack project that demonstrates product thinking, scalable architecture, and a polished developer experience. However, the back-end is omitted from this repository for obvious reasons.

## Features
- Create short, memorable links from long URLs.
- Manage links through a clean dashboard.
- Track essential analytics such as clicks, referrers, and timestamps.
- Support custom aliases for branded or readable links.
- Add expiration dates or deactivate links when needed.
- Generate QR codes for easy sharing.

## Stack
This project can be run with a modern web stack such as:
- Frontend: Next.js, React, TypeScript, Tailwind CSS
- Backend: Next.js API routes or a separate Node.js service
- Database: Supabase.js (PostgreSQL)
- Authentication: Supabase Auth
- Hosting: Vercel for the frontend and hosted Postgres/Supabase for data

## Use Cases
PlumURL is suitable for:
- Personal link management
- Marketing campaign tracking
- Branded short links for businesses
- QR code generation for print and event materials
- Portfolio demonstration of full-stack engineering skills
